# Support

Use GitHub Discussions for deployment questions, design ideas, and general
usage. Use an issue for reproducible software defects or approved feature
requests.

Before opening an issue:

1. read the [quick start](README.md#five-minute-start);
2. check the [documentation index](docs/README.md);
3. run `make validate`; and
4. remove credentials, private frames, public IP addresses, and identifying
   route or vehicle information.

Include the Git revision, operating system, Python version, selected backend,
device type, sanitized command, and complete error message.

Do not use public issues for vulnerabilities. Follow [SECURITY.md](SECURITY.md).
